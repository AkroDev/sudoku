# Sudoku AkroLabs

Application Sudoku indépendante, destinée à s'intégrer à l'univers visuel d'AkroLabs.

## Direction technique

- Next.js
- React
- TypeScript
- Tailwind CSS
- V1 locale dans le navigateur
- Supabase prévu dans une phase ultérieure pour les comptes, les scores et le Hall of Fame

Le site vitrine AkroLabs reste dans son dépôt Astro séparé. Ce dépôt contient uniquement l'application Sudoku.

## État

Dépôt initialisé. Le socle Next.js et la première grille fonctionnelle seront ajoutés dans les commits suivants.
